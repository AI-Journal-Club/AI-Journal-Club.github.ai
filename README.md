# ASPIRE Workshop 2027

Single-file website — LSU AI Journal Club in conjunction with TIAMS, Feb 19–20, 2027.

## Files
- `index.html` — the whole site (all pages, styles, banner)
- `photos/` — speaker and committee photos (see `photos/README.txt` for exact file names)

## Photos
Upload square JPGs to `photos/` using the listed names. Initials show until a photo exists.

## Deploy on GitHub Pages
Push these files to a repo, then Settings → Pages → deploy from branch `main`, folder `/ (root)`.
